a) ¿Qué secciones identificas dentro del código?

Dentro de este código HTML se pueden identificar principalmente dos secciones: head, body, La sección head contiene información de configuración de la página, mientras que body contiene el contenido que se muestra al usuario.

b) ¿Puedes determinar qué función cumple cada sección del sitio?

si, la sección head sirve para configurar información de la página, como el título y la codificación de caracteres. La sección body contiene el contenido visible, como títulos y textos.

c) Diferencias entre Visual Studio Code y Bloc de Notas

Visual Studio Code está diseñado para trabajar con código y ofrece herramientas como colores para las etiquetas, autocompletado y detección de errores. El Bloc de Notas es más básico y solamente permite editar texto.

En mi opinión, Visual Studio Code brinda mayores beneficios porque facilita la programación y permite trabajar con el código de una forma más ordenada.

d) ¿Qué sucedería al cambiar H1 por H3 ?

Si se cambia H1 por H3, el título aparecerá más pequeño. Esto ocurre porque los encabezados HTML tienen diferentes niveles de tamaño e importancia.

¿Qué sucedería al cambiar P por strong?

El texto dejaría de comportarse como un párrafo y aparecería destacado, normalmente en negrita.

e) Agregar texto entre las líneas 10 y 11

Al ingresar un texto dentro del body, este aparecerá en la página web después de guardar el archivo y recargar el navegador.

También se pueden agregar efectos como cambiar el tamaño, color, alineación y tipo de letra utilizando HTML y CSS. Además, se pueden utilizar etiquetas como strong para destacar texto o EM para darle énfasis.
